# Part 1A

Part 1A is the completed Smart Todo & Task Manager application.

To preserve the already validated workspace configuration, its implementation
remains at the repository root:

- Specification artifacts: `specs/001-smart-todo-task-manager/`
- Backend: `backend/`
- Frontend: `frontend/`
- Shared contracts: `packages/contracts/`
- Independent harness: `harness/`
- Harness log: `harness-log.md`

Run Part 1A from the repository root:

```sh
npm install
npm run harness
```
