# Part 1B — Natural-Language Reminder Agent

Run `npm install`, then `npm test`, `npm run type-check`, `npm run build`, and `npm run evaluate`. The application uses the external OpenAI-compatible adapter by default; configure `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, and `LLM_TIMEOUT_MS`. Set `REMINDER_MODE=deterministic` only for offline deterministic evaluation. No calendar, messaging, or notification action is executed.
